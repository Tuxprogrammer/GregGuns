## Branding and infographics

All generated by `python tools/asset-gen/branding.py` (SVG sources, then PNG exports; `--svg-only` skips the rasterizer). Original artwork, not derived from Techguns. Credits: [CREDITS.md](CREDITS.md).

**branding/**
- `logo.svg`, `logo_128.png` (mcmod.info `logoFile`), `logo_512.png`: steel hex casing, rifle silhouette, GT blue cable and orange bullet.
- `logo_pixel.svg`, `logo_pixel_32.png`, `_128`, `_256`: pixel-crisp 32 x 32 variant for small sizes.
- `banner.svg` / `banner.png`: 1280 x 320, README header.
- `social_preview.svg` / `social_preview.png`: 1280 x 640, GitHub social preview.

**infographics/** (dark card, readable on light or dark pages)
- `tier-progression`: weapons, armor and ammo per GT tier with gate materials (design 0001, 0009, 0010).
- `machine-roster`: single block to multiblock, usage class, tier range, isometric sketches of the four multiblocks.
- `ammo-production-flow`: GT materials to parts to Ammo Press or Ammunition Works to ammo, magazines and guns.
- `questbook-overview`: 118 quests in 14 chapters and their pack gates.
- `multiblock-ammunition-works`, `multiblock-retort`, `multiblock-armory-gantry`, `multiblock-rampart`: one explainer each (isometric sketch with numbered controller and hatch markers, layer grids, size and expandable segments, tier and parallel mechanic).
