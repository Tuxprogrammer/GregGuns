# Textures

This page covers all 49 files in `textures/fx/`, plus the `textures/entity/` projectile textures that the renderers in this area bind. **No FX texture has a `.mcmeta` file.** All animation is code-driven: the sprite-sheet grid and frame count come from the code or data file that uses the sheet. Frames are numbered left to right, then top to bottom. The rest of a grid's cells stay empty (transparent or black).

Conventions used in the tables:
- **Blend** is how the texture is drawn (see [particle-system.md §3.4](particle-system.md#34-render-types)). Textures drawn additively are painted on **opaque black** (black = invisible), usually saved as RGB with no alpha channel or with alpha 255 everywhere. Alpha-blended textures use real transparency.
- "Tinted" means the grey or white art is multiplied by a code-supplied colour, so it should be painted neutral.
- Palette is the dominant colours in the visible parts.

## Measured palette and frame rectangles (all 56 textures)

This section was added in the consistency pass. The average colour, dominant colours and opaque share are quoted unchanged from [ASSET-FACTS.md](../ASSET-FACTS.md):
- **Average** is the mean of pixels with alpha > 16.
- **Dominant** buckets each channel into 8 levels.
- **Opaque** is the share of all pixels with alpha > 16.

Additive textures are fully opaque by construction. Their black background therefore dominates the measured average, and the visible colour is the non-black part described in words.

The descriptive "Palette" column in the tables above was based on looking at the images. Where it differs from the numbers below, the numbers are measured and win. For example, the `entity/bullet.png` row above gave a probe of the 16×5 used region (≈ 220, 210, 155 cream-brass), while the whole-sheet average below is #C68E47.

Frame rectangles are given as `(x0,y0)-(x1,y1)` in pixels, with frames numbered left to right, then top to bottom. The grid is the one the *using code* applies (see the sprite-sheet table above for the frame counts each user reads). No texture here has an `.mcmeta` file, so none is a vertical-strip animation in the vanilla sense. `nukebeam.png` is animated by `RenderMovingBeam` (1 frame per 2 ticks) and `fireblast.png` and others by the particle code.
