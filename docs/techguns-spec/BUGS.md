Every suspected bug the spec agents found in Techguns 0.1.2, merged across areas. These are bugs in **Techguns**, not GregGuns. They are listed so the rewrite doesn't reproduce them. Nothing here has been confirmed at runtime, and no fixes are designed.

381 raw findings merge into **337 unique bugs**: 32 crash, 136 gameplay, 55 visual, 114 cosmetic.

The **ID** is the first area's ID; **also** lists the same bug as reported by other areas. Full context is in each area's `index.md`.
