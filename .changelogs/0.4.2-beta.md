# GregGuns 0.4.2-beta

> [!WARNING]
> **This is a beta.** This fix was checked by unit tests, on a dev server, and on the official GTNH 2.9.0 server pack, but has not had a long public playthrough. Back up your world before you update.

A fix for the Vending Machine: GregGuns trades now open with the pack's own tier quests, so a player sees them as soon as they reach a tier, even if they added GregGuns partway through a playthrough.

## Read this first (server owners)

- **Tested on GTNH 2.9.0.** Replace the jar on the server and on every client.
- **Drop-in from 0.4.1-beta.** No pack file or config changes.

## Upgrading

### From 0.4.1-beta

Nothing to do beyond replacing the jar. GregGuns trades a player has already reached appear within about 10 seconds of joining.

### From 0.4.0-beta or earlier

Read the [0.4.1-beta notes](https://github.com/Tuxprogrammer/GregGuns/releases/tag/0.4.1-beta) first; everything in them applies.

## Fixed

- **Vending Machine trades.** Each tier's GregGuns trades open with the pack's own tier quest: Welcome to Tier 0.5, Steam! (Steam), Welcome to Tier 1, LV, then Tier 2 (MV) through Tier 7 (ZPM). Before, they waited for the GregGuns chapter intro quests. A player who had not done those, for example one who added GregGuns mid-game, saw no GregGuns trades at all, and coins put in the machine bought nothing.
- **GregGuns Coin.** The tooltip says where the coin goes: the Vending Machine's input slots. The machine's coin wallet takes only the pack's own coins, so GregGuns Coins pay from the input slots, or from ME through the Uplink Hatch. A trade takes the coin value it names (6 x Coin 10 takes Coin 10s); break larger coins into smaller ones in a crafting grid.
