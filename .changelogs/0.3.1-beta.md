# GregGuns 0.3.1-beta (pre-release)

## The questbook ships in the jar

The GregGuns quest line is now inside the GregGuns jar and installs itself into BetterQuesting on request. Nothing changes in the GTNH pack and no pack file needs editing. It is optional and **off by default**.

- **Turn it on:** set `questbook.install=true` in `config/gregguns.cfg` (the `questbook` block; it is not shown in the in-game config GUI), then restart the server. The log shows `Installed/updated GregGuns quest line: N quests`.
- **Player progress is safe.** The install only adds or updates the GregGuns quests and the GregGuns tab. Other quests and tabs, and everyone's progress, are untouched. You can leave the key on: each start refreshes the GregGuns quests and keeps progress.
- **Turn it off:** setting the key back to `false` does nothing; an installed line stays. To remove it, delete the GregGuns tab and its quests in BetterQuesting edit mode (`/bq_admin edit`) with the key off. See `docs/config.md`, "Hidden keys".
- Needs BetterQuesting (in the GTNH pack). Without it the key is ignored.
- **121 quests**, including new ones for the Ammunition Works, the filling bench, the Armory Gantry and the Bio Gun line.
- **In the GTNH pack the tab goes back to last place on every start.** The pack's `config/modpack-update` file makes it reload its default quests each boot, so the GregGuns line is added again after them. Progress is kept.

## Upgrading

Drop-in from 0.3.0-beta: replace the jar on the server and on every client. No config or world changes are needed.

## Known issues

- **Shader packs:** near water, while an energy weapon's effect is on screen (De-Atomizer, Scatter Laser and others), a rectangle around the crosshair can show no water surface, so you see straight through to the bottom. It goes away when the effect ends. A fix is in progress.
- Everything listed for [0.3.0-beta](https://github.com/Tuxprogrammer/GregGuns/releases/tag/0.3.0-beta) still applies.
