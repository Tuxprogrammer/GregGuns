# Unreleased

Notes for the next release. Fold these into that release's changelog when it is cut.

- Player guides: the recipes, enemies, Ammunition Works and Armory Gantry sheets now show Minecraft's real textures (ingredient icons, the Skeleton and Zombie Pigman Soldier skins, the interior lamp) instead of our stand-ins, credited in each sheet's footer.
- Structures on Ross128 (design record 0019): the M8 structures now also generate on Ross128b and Ross128ba, read from BartWorks' `ross128BID` and `ross128BAID`. New config `worldgen.structureRoss128` (default on) and `worldgen.ross128CeilingWeights`. Each structure there rolls its own loot ceiling from MV to UHV, weighted to the low end, and its hole spawners' NPCs start tougher with it. Four new loot tiers (EV to ZPM) back the high rolls. Galacticraft skips Forge world generators on those two dimensions, so GregGuns hooks their chunk providers itself.
- OpenModularTurrets overlap investigation finished (design record 0020): the Turret and Rampart stay, with no code or pack changes. A new unit test pins which of our entities OMT turrets will and will not shoot.
- Translation readiness: every player-visible string is a lang key. The "module is off" tooltip and chat line, the Ammo Pouch inventory name and every GT machine name moved into `en_US.lang`; the questbook text is now in the lang file too (`betterquesting.quest.<id>.*`), which BetterQuesting reads first. A new `LangFilesTest` checks code keys, extra translation files and placeholders. How to add a language is in `docs/translating.md`.
- Pack fit from the jar: GregGuns now adds its guns to Backhand's offhand lists, `gregguns.` to AngerMod's butcher items, `gregguns.SimpleTurret` to Mobs Info's blacklist and Thaumcraft scan aspects for its NPCs, all in memory at startup (new `compat.*` keys, default on; no other mod's config file is written). The Attack Helicopter never rolls as an infernal mob. PACK-CHANGES.md now gives every row a status: done in the jar, an optional server-owner step with the exact file, or not applicable.
- NEI: technical items are hidden, and new item subsets `GregGuns.Guns`, `GregGuns.Ammo` and `GregGuns.Armor` appear in NEI's subset menu. The `debug` config category is now hidden from the config GUI.
- In-game guide: GregGuns now ships its own GuideNH guide (press G, or hold G over a GregGuns item): getting started, guns by tier, ammo and magazines, armor and gear, machines with the Ammunition Works, Armory Gantry and Rampart, enemies and loot, and pack notes. It is plain resource pages, so the mod loads the same without GuideNH.
- Balance pass along the GT tiers (design record 0021): Steam Armor Plating needs 1 titanium plate instead of 2 (a Steam set was 48 titanium plates for MV-grade protection); the LuV Alien Blaster holds 25 shots per charge (was 10); the IV Power Armor and Exo Suit chestplates hold 2,000,000 and 4,000,000 EU (were 720,000 and 1,440,000), so a full set walks 42 and 83 minutes instead of 15 and 30. Damage numbers are unchanged. The record lists the open judgment calls for the playthrough.
